# Платформа корпоративного обучения сотрудников

MVP для демонстрации базового сценария: создатель публикует и назначает курс, сотрудник изучает материалы и проходит итоговый тест, после успешного результата подтверждаются полученные навыки. Приложение использует NestJS, React и PostgreSQL. Для демо не нужны облачные сервисы, почта, брокер сообщений или файловое хранилище.

## Запуск в Windows

Нужен Node.js 24 или новее и Docker.

1. Клонируйте репозиторий

   ```powershell
   git clone https://github.com/HarsatMKad/project-employee-training
   cd ./project-employee-training
   ```

2. Запустите Docker, соберите docker-compose

   ```powershell
   docker compose up --build
   ```

   После сборки откройте `http://localhost:3000`. 

При первом запуске backend автоматически заполнится демо-данными, добавлит демо-организацию, две учетные записи для входа, шесть дополнительных сотрудников каталога и пример навыка.

## Демо-учетные записи

| Роль | Почта | Пароль |
|---|---|---|
| Создатель | `hr@demo.local` | `Demo123!` |
| Сотрудник | `employee@demo.local` | `Demo123!` |

На экране входа есть переключатель демо-профилей.

## Сценарий демонстрации

1. Войдите как создатель, создайте и опубликуйте курс с текстовым уроком и тестом с вариантами ответа.
2. При необходимости добавьте навыки во вкладке «Навыки», выберите один или несколько в конструкторе курса и настройте порог теста.
3. В разделе «Список курсов» нажмите «Назначить сотрудника» и выберите сотрудника.
4. Откройте рабочее место «Сотрудники», отфильтруйте список и просмотрите подтвержденные навыки команды.
5. Для прохождения назначенного курса войдите под учетной записью сотрудника, отмечайте изученные материалы и сдайте итоговый тест с результатом не ниже заданного порога.
6. Проверьте появление подтвержденных навыков в рабочем месте «Сотрудники» и прогресс в карточке курса.
