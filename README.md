# Платформа корпоративного обучения сотрудников

Локальный MVP для демонстрации базового сценария: создатель публикует и назначает курс, сотрудник изучает материалы и проходит итоговый тест, после успешного результата подтверждаются связанные навыки.

## Возможности демо

- Два профиля для входа: создатель курса и сотрудник одной демо-компании.
- Рабочее место создателя со списком сотрудников, фильтрами по отделам «отдел1–3» и должностям в компании «сотрудник/тимлид», а также подтвержденными навыками.
- Курсы из текстовых уроков и необязательных внешних ссылок на видео.
- Выбор нескольких навыков для курса и управление каталогом навыков организации.
- Тест до 40 вопросов с 2–8 вариантами ответа на каждый вопрос и настраиваемым порогом прохождения.
- Публикация курса отдельно от назначения; назначение сотруднику доступно в разделе «Мои курсы» с фильтрами по отделу и должности.
- Шесть дополнительных демо-сотрудников для просмотра и назначения курсов; у них нет отдельных демо-учетных записей для входа.
- Подтверждение связанных навыков после успешного итогового теста; отметки об изучении материалов сохраняются отдельно и не влияют на прогресс курса.
- JWT-сессия в HttpOnly cookie и хэширование паролей.

Приложение использует NestJS, React и PostgreSQL. Для демо не нужны облачные сервисы, почта, брокер сообщений или файловое хранилище.

## Запуск в Windows

Нужен Node.js 24 или новее.

1. В первом окне PowerShell запустите backend:

   ```powershell
   docker compose up -d database
   cd employee-training-backend
   $env:DATABASE_URL = "postgres://postgres:postgres@localhost:5432/employee_training"
   yarn install
   yarn start:dev
   ```

   API доступен на `http://localhost:3001/api/v1`; проверка состояния — `http://localhost:3001/api/v1/health`.

2. Во втором окне PowerShell запустите frontend:

   ```powershell
   cd employee-training-frontend
   npm install
   npm start
   ```

   Откроется `http://localhost:3000`. CRA перенаправляет `/api` запросы на backend.

При первом запуске backend автоматически создаёт схему PostgreSQL и идемпотентно добавляет демо-организацию, две учетные записи для входа, шесть дополнительных сотрудников каталога и пример навыка. Новые сотрудники появляются без подтвержденных навыков; они отображаются после успешного прохождения назначенного курса. Существующий файл SQLite не импортируется, его данные остаются отдельно.

Чтобы запустить весь стек в Docker:

```powershell
docker compose up --build
```

PostgreSQL доступен на `localhost:5432`; Compose сохраняет его данные в именованном томе `postgres-data`.

## Демо-учетные записи

| Роль | Почта | Пароль |
|---|---|---|
| Создатель | `hr@demo.local` | `Demo123!` |
| Сотрудник | `employee@demo.local` | `Demo123!` |

На экране входа есть переключатель демо-профилей.

## Сценарий демонстрации

1. Войдите как создатель, создайте и опубликуйте курс с текстовым уроком и вопросом с вариантами ответа.
2. При необходимости добавьте навыки во вкладке «Навыки», выберите один или несколько в конструкторе курса и настройте порог теста.
3. В разделе «Мои курсы» нажмите «Назначить сотрудника», при необходимости отфильтруйте список по отделу и должности и выберите сотрудника.
4. Откройте рабочее место «Сотрудники», отфильтруйте список и просмотрите подтвержденные навыки команды.
5. Для прохождения назначенного курса войдите под учетной записью сотрудника, отмечайте изученные материалы и сдайте итоговый тест с результатом не ниже заданного порога.
6. Проверьте появление подтвержденных навыков в рабочем месте «Сотрудники» и прогресс в карточке курса.

## Локальные настройки

- Backend: `PORT` (по умолчанию `3001`), обязательный `DATABASE_URL`, `JWT_SECRET`.
- Для локального запуска backend используйте `postgres://postgres:postgres@localhost:5432/employee_training`; внутри Compose backend подключается к `database:5432`.
- В production необходимо задать `JWT_SECRET`; приложение откажется стартовать при его отсутствии. В локальном демо используется встроенный ключ по умолчанию.
- Compose сохраняет данные PostgreSQL в томе `postgres-data`; удаление этого тома полностью сбрасывает базу.

Демо упрощает описанную в отчете многоарендную систему до одной заранее созданной организации. Регистрация организаций, приглашения пользователей, восстановление пароля, файловое хранилище, уведомления, резервные облака, платежи и ИИ-функции в MVP не входят.

Удаление навыка требует подтверждения и снимает его со связанных курсов и из профилей сотрудников.
