# Платформа корпоративного обучения сотрудников

Локальный MVP для демонстрации базового сценария: создатель публикует и назначает курс, сотрудник проходит уроки и тест, после успешного результата подтверждаются связанные навыки.

## Возможности демо

- Два профиля: создатель курса и сотрудник одной демо-компании.
- Курсы из текстовых уроков и необязательных внешних ссылок на видео.
- Выбор нескольких навыков для курса и управление каталогом навыков организации.
- Тест до 40 вопросов с 2–8 вариантами ответа на каждый вопрос и настраиваемым порогом прохождения.
- Назначение курса сотруднику, сохранение прогресса и повторные попытки теста.
- Подтверждение связанных навыков после завершения всех уроков и успешного теста.
- JWT-сессия в HttpOnly cookie и хэширование паролей.

Приложение использует NestJS, React и встроенную в Node.js SQLite. Для демо не нужны Docker, облачные сервисы, почта, брокер сообщений или файловое хранилище.

## Запуск в Windows

Нужен Node.js 24 или новее.

1. В первом окне PowerShell запустите backend:

   ```powershell
   cd employee-training-backend
   yarn install
   yarn start:dev
   ```

   API доступен на `http://localhost:3001/api/v1`; проверка состояния — `http://localhost:3001/api/v1/health`.

2. Во втором окне PowerShell запустите frontend:

   ```powershell
   cd employee-training-frontend
   npm install
   npm start
   ```

   Откроется `http://localhost:3000`. CRA перенаправляет `/api` запросы на backend.

При первом запуске backend создаст `employee-training-backend/data/training.sqlite` и заполнит демо-организацию, две учетные записи и пример навыка.

## Демо-учетные записи

| Роль | Почта | Пароль |
|---|---|---|
| Создатель | `hr@demo.local` | `Demo123!` |
| Сотрудник | `employee@demo.local` | `Demo123!` |

На экране входа есть переключатель демо-профилей.

## Сценарий демонстрации

1. Войдите как создатель, создайте курс, добавьте текстовый урок и вопрос с вариантами ответа.
2. При необходимости добавьте навыки во вкладке «Навыки», выберите один или несколько в конструкторе курса и настройте порог теста, затем опубликуйте и назначьте курс Ивану Петрову.
3. Выйдите и войдите как сотрудник.
4. Откройте курс, завершите каждый урок и сдайте тест с результатом не ниже заданного порога.
5. Проверьте процент прохождения и появление подтвержденных навыков в профиле.
6. Вернитесь в профиль создателя: статус, прогресс и последний результат теста отображаются в обзоре курса.

## Локальные настройки

- Backend: `PORT` (по умолчанию `3001`), `DB_PATH` (по умолчанию `employee-training-backend/data/training.sqlite`), `JWT_SECRET`.
- В production необходимо задать `JWT_SECRET`; приложение откажется стартовать при его отсутствии. В локальном демо используется встроенный ключ по умолчанию.
- Для сброса демонстрационных данных остановите backend и удалите файл `employee-training-backend\data\training.sqlite`. При следующем старте он будет создан заново.

Демо упрощает описанную в отчете многоарендную систему до одной заранее созданной организации. Регистрация организаций, приглашения пользователей, восстановление пароля, файловое хранилище, уведомления, резервные облака, платежи и ИИ-функции в MVP не входят.

Удаление навыка требует подтверждения и снимает его со связанных курсов и из профилей сотрудников.
